# Sound library

Drop downloaded sound files here (`.wav`, `.mp3`, `.m4a`). This folder is for
auditioning and picking; nothing in it plays until it is wired up.

- Audition: `afplay assets/audio/library/<file>.wav`, or select the file in
  Finder and press Space.
- Wire one up: point its id at the file in `src/services/audio/registry.ts`,
  e.g. `meterTopUp: require('../../../assets/audio/library/<file>.wav')`.
- Keep the source and license next to the file when it is not CC0
  (`<file>.license.txt`: where it came from, the license, attribution if any).

The synthesized placeholders live one level up in `assets/audio/` and are
regenerated by `scripts/generate-placeholder-sounds.mjs`.
