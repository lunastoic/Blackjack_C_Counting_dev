# Default card faces

The 52 faces in this folder are from **The Public Domain Deck** by Austin Gabriel
(https://github.com/AustinGabriel/The-Public-Domain-Deck-Public-Domain-and-CC0-Playing-Cards),
released under CC0 1.0 (see `LICENSE-CC0.txt`) — no attribution required, commercial use allowed.
Only `png cards/card fronts/{clubs,diamonds,hearts,spades}` were taken; they were resized
from 1500×2100 to 500×700 and flattened onto white (the source has transparent rounded corners).

`deck-cover.png` (the card back) is the app's own art. The previous house faces live in
`assets/luna-cards/` as the `luna` skin.
